# Project memory

## Brand
- Platform name: **Kinetic Layers** (never abbreviate to "Klin" — that was a discarded name)
- Domain: **kineticlayers.com**
- Studio positioning: one studio, drops every Thursday, 240 assets, 12 free
- Paid tier is called **Premium** ($24/mo) — not "Unlimited"

## Design system (see "Kinetic Layers Plan.dc.html")
- Light mode is the default; dark mode is available via the header toggle
- Type: Figtree (300/400) + Cormorant italic for one pull line per page + Geist Mono for labels
- Tokens: warm-white ground, graphite ink, one amber lamp (#E8853A glow, #A4501A as text), moss (#3D5A4C) for status
- Primary buttons are glass (translucent + blur + inset highlight), never solid amber
- Premium CTA is the one unique button: amber-lit glass, magnetic, with a shine sweep
- Motion is GSAP everywhere, but reactive — it moves because the user moved
